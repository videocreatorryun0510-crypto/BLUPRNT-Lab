# Presentation Artifact Contract

Presentation Artifact Version 1.0 is the provider-neutral, renderer-neutral
educational output contract for BLUPRNT Lab.

It copies approved medical assertions from a Source Bundle without rewriting
them, arranges those assertions into pages, and preserves claim and reference
traceability. It intentionally contains no Gemini, API, model, coordinate,
font, color, or output-file instructions.

Future PowerPoint, PDF, HTML, Instagram, Canva, and other renderers consume the
same validated Artifact through the `Renderer` protocol.
