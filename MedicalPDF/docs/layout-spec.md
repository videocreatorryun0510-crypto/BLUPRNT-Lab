# MedicalPDF Phase 1 レイアウト仕様

## 目的

固定された疾患データから、A4縦・1ページの医療教育資料を再現可能に生成するための物理レイアウトを定義します。

## ページ

| 項目 | 値 |
|---|---|
| 用紙 | A4縦、210 × 297 mm |
| 基本余白 | 12 mm |
| 本文 | 2カラム |
| カラム間 | 8 mm |
| 最小本文文字 | 8.2 pt |
| 参考文献文字 | 6.6 pt |
| 生成エンジン | ReportLab 4系 |
| 日本語フォント | `MEDICALPDF_FONT_PATH`、OSフォント、CIDフォントの順に解決 |

参考文献は限られた領域に収めるため本文より小さくしますが、出典3件を人が読めることをGolden Testで確認します。正式版の最小文字サイズは医療監修・アクセシビリティレビューで再決定します。

## ワイヤーフレーム

```text
┌────────────────────────────────────────┐
│ BLUPRNT LAB              [教育用ドラフト] │
│ 疾患名                                  │
│ English name / aliases                  │
├────────────────────────────────────────┤
│ ひとことで理解                           │
├───────────────────┬────────────────────┤
│ 病態・原因          │ 治療・管理           │
│                   │                    │
├───────────────────┼────────────────────┤
│ 症状・所見          │ Red Flags          │
│                   │                    │
├───────────────────┼────────────────────┤
│ 検査・診断          │ 国家試験ポイント      │
│                   │                    │
├───────────────────┴────────────────────┤
│ 出典                                   │
├────────────────────────────────────────┤
│ 文書ID / 版 / 日時 / 免責                 │
└────────────────────────────────────────┘
```

## 色

| 用途 | 色 |
|---|---|
| 主見出し | Navy `#17324D` |
| 基本強調 | Teal `#168C88` |
| 警告 | Red `#B5413E` |
| 試験ポイント | Gold `#C98A14` |
| 本文 | Ink `#22313F` |
| 罫線 | Border `#D6E0E6` |

色だけに意味を依存させず、見出し文字を常に併記します。

## フィットルール

1. 各セクションを描画前に計測する
2. 本文領域を超えるセクションは描画しない
3. タイトルは最大2行とする
4. ひとこと要約は予約領域を超えたら失敗する
5. 出典は3〜5件を想定し、予約領域を超えたら失敗する
6. フォントを規定値未満へ自動縮小しない
7. 2ページ目を作成・破棄しない
8. 失敗時は `LayoutOverflowError` として上位処理へ返す

## 自動検証

- PDFページ数が1
- ページ寸法がA4縦
- 必須見出しとレビュー状態を抽出可能
- 文字座標がページ外にない
- 置換文字や黒四角が抽出されない

自動検証は視覚確認を代替しません。変更後はPopplerでPNGへレンダリングし、文字切れ、重なり、余白、可読性を確認します。
